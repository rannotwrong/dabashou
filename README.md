# 一技之友 · 技能互换平台

在线体验：https://rannotwrong.github.io/dabashou/

纯静态交互原型，保留黑白灰与少量操作蓝；不依赖框架、CDN 或第三方字体。

## 本次产品结构

- **发现**：分别维护多项能教、想学的技能，推荐所有双向互补组合。优先按时段交集排序，同一伙伴汇总多个可交换技能；时段相同不代表已预约。
- **无结果**：区分缺少供给、技能不互补、时间不合适、已跳过等原因。支持补充技能、修改目标、放宽时间、恢复推荐、保存新匹配意向。
- **用户档案**：简短介绍、教学范围、适合水平、可展开的能力材料、完成与守约示例记录。新伙伴明确显示暂无记录。
- **我的**：独立添加、编辑、移除能教／想学技能，支持自定义技能名称；学习目标为可选参考信息。管理时间与已保存的订阅意向。
- **互换**：技能选择、目标、具体日期、双方分别约定投入。支持未定时间先协商；尚无未来具体日期时不能接受预约。

## 完整流程

发送方案 → 对方接受或提出新方案 → 双方确认 → 开始互换 → 双方分别完成教学 → 双方分别确认学习结果 → 评价／再次互换。

改期会使原约定失效，需要另一方重新确认。部分达到、暂未达到的结果如实保留；已完成状态不代表双方都达到学习目标。取消保留原方案与已经完成的教学记录。重复的进行中交换会跳转到已有记录。

详情页下方的「演示对方操作」可模拟回应、改期、教学与成果确认。为了演示，可在双方确认后立即开始，无需等待约定时间。不会开启真实课堂。

## 演示与数据边界

- 所有人物、能力材料、历史次数及反馈均为虚构示例，不代表认证或真实履约。
- 无账号、后台、实时通信、支付或真实通知；操作只保存到当前浏览器 localStorage。
- 「订阅新匹配」仅保存本地意向，可在「我的」取消，不发送外部通知。
- 推荐是明确的技能与时间规则，没有 AI 语义匹配或未经校准的匹配分。
- 旧版 `dabashou-cards-v2` 自动拆分为独立供需，去重技能并保留发出的邀请快照；不删除旧存储键。新版使用 `dabashou-skills-v3`。
- 编辑或删除个人技能不会改写已经发出的交换方案。

## 本地运行与验证

```sh
npm start
# 浏览 http://127.0.0.1:4173
npm test
```

`app.js` 管理界面，`core.js` 负责匹配、迁移和状态流转，`data.js` 为示例材料。原生 Node 测试覆盖跨技能组合、时间条件、无结果诊断、双向履约、协商重新确认、取消留痕与旧数据迁移。

## 发布

GitHub Pages 从 main 分支根目录发布。地址与仓库名保持不变。发布后需确认 Pages 构建成功及线上 HTML、脚本与样式一致，并实际打开页面检查。
