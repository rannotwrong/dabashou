# 搭把手 · 技能互换平台

用你会的，换你想学的。Vibe Coding 交互雏形。

## 功能

- 发布我能教的 / 我想学的技能名片
- 按技能、学习方式、双向需求发现伙伴
- 展示推荐原因和学习目标
- 模拟交换邀请、接受、学习进度
- 响应式布局，手机和电脑均可使用

## 演示边界

示例人物不代表真实用户。操作保存在当前浏览器 localStorage，不包含真实消息发送、登录或云端数据同步。

## 部署和维护

纯静态 HTML、CSS、JavaScript，无外部字体、CDN、图片或运行时 API 依赖。GitHub Pages 从 main 分支根目录发布。提交同一仓库的 main 分支即可更新网站，勿重命名仓库或更改域名。

GitHub Pages 部署成功不代表中国大陆所有运营商和地区都可达，实际提交前仍需使用不同网络验收。
