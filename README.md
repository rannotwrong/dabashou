# 搭把手 · 技能互换平台

用你会的，学你想学的。

在线体验：https://rannotwrong.github.io/dabashou/

## 当前产品

以「技能交换卡」为匹配单位，每人最多创建三张卡，每张卡包含一项我的技能、一项想学技能、具体目标、可用时间和是否可协商。用户选择一张自己的卡片，浏览互补推荐。

### 发现

- 我想学 / 我想教：调整推荐卡技能与目标的展示顺序。
- 技能双向互补、线上实时、共同时间或可协商；共同时间优先，同一用户去重。
- 纵向滑动，支持上一张 / 下一张及键盘上下键。
- 收藏、收藏回看、查看档案、暂不考虑、重置筛选与跳过。
- 费用仅作意向备注；要求支付费用的卡片不参与互换推荐。

### 互换

确认我教什么、我学什么后，填写未来的提议时间，或勾选可协商。双方各投入 30 分钟，线上实时。模拟邀请保存后显示「待对方回应」，可查看或撤回。

发出邀请不等于对方接受，也不等于已预约或已履约。真实回应、双方计划确认、提醒、改期、双向履约与满意度反馈暂未实现。

### 我的

创建、编辑、删除最多三张交换卡；展示学习目标与合作条件。删除交换卡会清理对应收藏与跳过标记，已发出的邀请保留发送时的内容快照，可单独撤回。

## 设计

参考用户提供的匹配卡片交互与文案，保持苹果官网风格的黑、白、浅灰及少量操作蓝。桌面左右分栏，手机上下排列；使用本机字体，不依赖外部字体、CDN 或图片。

## 演示边界

人物和供需均为虚构示例；不向其他用户发送消息。状态仅保存在当前浏览器 localStorage，刷新可保留，无账号或云端同步。旧版技能名片的数据不会自动转为新版交换卡。

当前推荐是明确的规则筛选，未实现目标语义理解、能力认证或学习型算法，不展示未经校准的匹配百分比。用户档案不参与匹配计分。费用字段不提供报价、订单、支付功能。

## 部署维护

纯静态 HTML、CSS、JavaScript。GitHub Pages 从 main 分支根目录发布。修改后更新同一仓库，保持仓库名和线上地址不变。

部署成功不代表中国大陆所有网络均可达。历史上已由用户确认联通网络可访问，其他运营商仍需分别实测。
